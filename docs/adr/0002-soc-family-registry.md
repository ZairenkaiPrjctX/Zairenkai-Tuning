# ADR 0002: SoC family detection is open-ended registry data

Status: accepted (2026-10-22).

## Context

Zairenkai must cover Qualcomm/Snapdragon (including the 7s and other series), MediaTek
(Helio, Dimensity), Samsung Exynos, Google Tensor and unknown future SoCs. The master prompt
forbids a frozen marketing-name list as the source of truth and requires raw identifiers to be
kept.

## Decision

- `crates/ztune-core/data/soc-registry.json` holds family rules, sources and labels; code
  (`soc.rs`) only interprets it. A rule matches a device tree compatible by vendor and model
  prefix (`qcom,sm…`, `mediatek,mt…`, `samsung,exynos…`, `google,gs…`), the Qualcomm socinfo
  `soc0/family` + `machine`, or an exact `ro.board.platform` value. Any matching identifier is
  reported raw, **listed or not**, so a new generation is detected without a code change.
- `known_platforms` is generated by `scripts/update-soc-registry.py` from a pinned Linux
  checkout (socinfo machine names, SoC compatibles in the arm bindings). It only says whether
  mainline Linux knows an id.
- Labels (marketing names) are display data with a source. Today they come from KonaBess
  (Qualcomm device tree model codenames). No MediaTek, Exynos or Tensor marketing label is
  shipped: no source fetched for this change states one.
- Two signals naming different families give `unknown`, not a guess. The GPU is never
  inferred from the SoC.

## Evidence used (all pinned in the registry)

Linux 7be4bc52 (socinfo.c, qcom/mediatek/samsung/google bindings); KonaBess ff387dc;
LineageOS device trees for gs101 (750d40c5), gs201 (f75ebcf4), zuma (9eeeb27b), garnet
(5b3cb512, board platform `parrot`; it states no SM number, so no "7s Gen 2" label is made).

## Rejected source

Lynx `references/dts/**/*.dtsi` (e56d6cd): 50–150-line reconstructions, not kernel
device trees (for example `sm7435.dtsi` claims `compatible = "qcom,sm7435", "qcom,sm6375"`).
They are not used as evidence.

## Consequences

Coverage grows by editing data plus a test. A family match is Tier S: read-only diagnostics
and unverified recommendations only.
